**Hippo Harbor CRM 0.2.0** — an offline student desktop CRM for Dr. Burchfield.

- **Windows x64:** open the downloaded setup file and follow the wizard.
- **macOS 13+ (Apple Silicon and Intel):** open the DMG and drag Hippo Harbor CRM into Applications.
- Offline Whisper and its model are included. No Rust, Cargo, Node or Python installation is needed.
- On first use, create a password and save your one-time recovery key privately.
